# ระบบสอบกลางภาค / ปลายภาค

ครูเปิดเมนู **สอบกลางภาค / ปลายภาค** เลือกภาคเรียน วิชา และห้อง แล้วกด **สร้างข้อสอบ** หนึ่งห้องมีข้อสอบกลางภาคและปลายภาคอย่างละชุด เลือกข้อเลือกตอบหรือข้อเขียน กำหนดคะแนนรายข้อให้รวมตรงคะแนนเต็มและไม่เกินสัดส่วนสอบของวิชา กำหนดเวลา 1–300 นาที และรหัสปลดล็อกครู 6–64 ตัวอักษร เก็บรหัสไว้กับครู บันทึกแล้วกด **เปิดการสอบ** นักเรียนจึงเริ่มได้

นักเรียนเปิดเมนู **สอบของฉัน** อ่านกติกาและยืนยันก่อนเริ่ม เวลาคิดจากเซิร์ฟเวอร์และเริ่มเมื่อเข้าสอบครั้งแรก คำตอบบันทึกหลังแก้ประมาณครึ่งวินาที การสลับแท็บ หน้าต่าง ซ่อนหน้า ออกจากหน้า รีโหลด หรือขาดอินเทอร์เน็ตจะล็อกหน้าสอบ การเปิดหน้าสอบเดิมใหม่ไม่ปลดล็อก ต้องให้ครูมาใส่รหัสบนหน้าสอบนักเรียน รหัสผิดเกิน 5 ครั้งต้องรอ 15 นาที หน้าที่เปิดก่อนการปลดล็อกใช้ส่งคำตอบต่อไม่ได้

คำตอบที่บันทึกแล้วอยู่ต่อหลังล็อกและปลดล็อก เวลาไม่หยุดระหว่างล็อก เมื่อหมดเวลาระบบปิดรับคำตอบและส่งคำตอบที่บันทึกไว้ การประมวลผลหมดเวลาจะเกิดเมื่อมีคำขอครั้งถัดไปจากนักเรียนหรือหน้าครู ไม่รับคำตอบย้อนหลังแม้ปิดอุปกรณ์ไว้ เมื่อไม่มีสัญญาณจากหน้าสอบเกิน 30 วินาที เซิร์ฟเวอร์จะล็อกในการตรวจครั้งถัดไป เพื่อรองรับกรณีปิดเบราว์เซอร์แล้วส่งเหตุการณ์ไม่ได้

ข้อเลือกตอบล้วนตรวจอัตโนมัติ หากมีข้อเขียนครูตรวจคะแนนรวมจาก **ดูคำตอบ / ประวัติ** กด **บันทึกคะแนนที่ตรวจ** แล้ว **ยืนยันคะแนนลงผลการเรียน** เพื่อบันทึกคะแนนจริงลงช่องกลางภาคหรือปลายภาค การยืนยันแทนที่คะแนนเดิมในช่องนั้นและถอนการเผยแพร่ผลเดิม นักเรียนดูคะแนนสอบผ่านผลการเรียนเมื่อครูเผยแพร่แล้ว เฉลยและรหัสปลดล็อกไม่ส่งให้ฝั่งนักเรียน

หลังนักเรียนเริ่มสอบแล้วแก้คำถาม เวลา หรือคะแนนเต็มไม่ได้ ครูยังปิด/เปิดสอบและเปลี่ยนรหัสปลดล็อกได้ ปิดสอบจะล็อกผู้ที่กำลังสอบก่อน การลบข้อสอบย้ายคำตอบเข้าถังขยะพร้อมกัน กู้คืนได้จาก **จัดการข้อมูล / ถังขยะ** การลบทะเบียนนักเรียน ห้อง วิชา หรือเทอมครอบคลุมการสอบในส่วนนั้นด้วย

ZIP สำรองเก็บข้อสอบ คำตอบ คะแนน และประวัติการล็อก โดยไม่เก็บรหัสปลดล็อกหรือโทเค็นหน้าสอบ กู้คืนเป็นรายวิชาใหม่และข้อสอบฉบับร่าง ครูต้องตั้งรหัสปลดล็อกใหม่ก่อนเปิดสอบ คำตอบเดิมและคะแนนที่ตรวจแล้วคงอยู่

## ขอบเขตการควบคุม

เว็บตรวจจับเหตุการณ์ที่เบราว์เซอร์รายงานและล็อกการส่งคำตอบที่เซิร์ฟเวอร์ ไม่สามารถห้ามปิดเบราว์เซอร์ ควบคุมทุกแอปในเครื่อง หรือรับประกันป้องกันการโกงได้ทั้งหมด เบราว์เซอร์บางรุ่น/อุปกรณ์และการปิดโปรแกรมกะทันหันอาจไม่แจ้งเหตุการณ์ทันที การสอบที่ต้องควบคุมอุปกรณ์ทั้งหมดควรใช้โหมด kiosk หรือเบราว์เซอร์สอบที่โรงเรียนจัดการร่วมด้วย อ้างอิง [Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API) และ [pagehide](https://developer.mozilla.org/en-US/docs/Web/API/Window/pagehide_event)

ทดสอบด้วยฐานข้อมูลจำลองเท่านั้น: `node tests/built-worker.mjs` รวมการสอบ 8 กลุ่ม ครอบคลุมสิทธิ์ เฉลย การล็อกถาวร รหัสปลดล็อก หน้าสอบเก่า การรีโหลด คะแนนจริง ข้อเขียน ถังขยะ สำรอง/กู้คืน การหมดเวลาและ heartbeat การตรวจ migration ใช้ `node tests/subject-migration.mjs`
